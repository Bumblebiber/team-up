        Communication

        How team-up and TIM reach you, and what happens when you answer.

        How it works

        1. Every job sends to one place — a Telegram bot, or only the bell at the top of this dashboard (no push on your phone).
        2. Every Telegram message ends with where it came from: 📂 folder · 🤖 CLI and model · 🧵 session. A report from a plain script says so instead.
        3. Reply to a message to continue its session. In Telegram, swipe the message (or long-press → Reply) and write. Your text goes into exactly that session; its answer comes back as a reply, with the same footer. A message from a script, or a message you write without replying to one, starts a new session (settings under Replies).

        Where messages go

        Most jobs stay silent until something needs you. A change applies to the next message.

        Bots

        + Add a bot
        1. In Telegram, write /newbot to @BotFather and pick a name. It answers with a token.
        2. Open the new bot and press Start — a bot may only write to chats that opened it.
        3. Paste the token here. team-up checks it with Telegram and keeps it in an owner-only file; this page only ever shows its last four characters.

        Leave the chat id empty: the bot then writes to you, like the others.
