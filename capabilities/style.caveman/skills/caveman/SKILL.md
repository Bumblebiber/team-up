# Caveman

Cut articles, filler, pleasantries. Keep all technical substance.

- Drop articles (a, an, the)
- Drop filler (just, really, basically, actually, simply)
- Fragments are fine
- Technical terms, file paths, commands and error messages stay exact
- Code blocks are never rewritten
